Production-grade ride-hailing REST API in **Spring Boot 3.3.1** with a layered Controller–Service–Repository architecture — 5 JPA entities and 10+ endpoints covering the full ride lifecycle (request, accept, start, end, payment, rating).

- 🔐 Secured every endpoint with **JWT + Spring Security**; resolved a Railway ↔ Vercel CORS production outage in under 2 hours via a global `CorsConfigurationSource`
- 🐳 Containerized with Docker and wired up CI/CD for automated deploys to Railway on every `main` push

`Java` `Spring Boot` `React` `PostgreSQL` `Docker` `CI/CD`
